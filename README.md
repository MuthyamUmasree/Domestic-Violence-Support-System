# Domestic Violence Support System

A web-based platform designed to connect domestic violence survivors with resources, support networks, and emergency services.

## Overview

The Domestic Violence Support System provides a safe, confidential environment for individuals affected by domestic violence to access help, report incidents, and connect with counselors and shelters. The platform prioritizes user safety with features like quick-exit buttons and discreet browsing.

## Features

- **Emergency Help**: One-click access to emergency contacts and hotlines
- **Resource Directory**: Searchable database of local shelters, legal aid, and counseling services
- **Incident Reporting**: Secure, anonymous reporting of domestic violence incidents
- **Counselor Chat**: Confidential messaging with trained support counselors
- **Safety Planning**: Guided tools to help survivors create personal safety plans
- **Legal Resources**: Information on restraining orders, legal rights, and court processes
- **Community Forum**: Moderated peer support community for survivors

## Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm or yarn
- A modern web browser

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/MuthyamUmasree/Domestic-Violence-Support-System.git
   cd Domestic-Violence-Support-System
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Set up environment variables:
   ```bash
   cp .env.example .env
   ```
   Edit `.env` with your configuration values.

4. Start the development server:
   ```bash
   npm run dev
   ```

## Usage

Visit `http://localhost:3000` in your browser after starting the server. The home page provides immediate access to emergency resources and the main navigation to all features.

## Safety Notice

If you are in immediate danger, please call **911** (US) or your local emergency number. You can also reach the **National Domestic Violence Hotline** at **1-800-799-7233** (TTY: 1-800-787-3224) or text START to 88788.
